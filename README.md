# Previous portfolio

The Kris.Dev design with the profile photo.

This is a standalone static website. It includes its own styles, JavaScript, favicon, resume, and every image used by its pages and project galleries. No build step is required.

## Upload

Upload all the contents of this folder to the root of your hosting destination or a separate GitHub Pages repository. Keep index.html at the top level and preserve the assets subfolders and filename capitalization. Do not upload the enclosing workspace or the other portfolio folder.

## Preview and edit

Open index.html directly or serve this folder with a static HTTP server. Edit this folder independently; changes do not synchronize with the other portfolio or the original workspace files. Google Fonts loads online, with local font fallbacks.
